# DL Lab: Colab challenge notebooks

Hands-on notebooks for the **LSTMs & Encoder-Decoder Models** workshop. Open one in Google Colab, pick a dataset, fill in the `# TODO`s, train on a free GPU, and submit your result to [DL Lab](https://dl-lab.dashovia.app).

| Notebook | Open | Datasets you can pick |
|---|---|---|
| 📱 Read the vibe: why LSTMs remember | [Open in Colab](https://colab.research.google.com/github/Meet2147/dl-lab-notebooks/blob/main/notebooks/01_sequence_models.ipynb) | GoEmotions · Tweet → emoji · IMDB |
| 🗣️ Build a translator: LSTM encoder-decoder | [Open in Colab](https://colab.research.google.com/github/Meet2147/dl-lab-notebooks/blob/main/notebooks/02_encoder_decoder.ipynb) | English → Hinglish · messy dates |

In Colab: **Runtime → Change runtime type → T4 GPU**, then paste the settings block from your DL Lab challenge page into the first cell.

Dataset credits: GoEmotions (Google, Apache-2.0), TweetEval (Cardiff NLP), IMDB (Stanford), English-to-Hinglish (findnitai, Apache-2.0).
