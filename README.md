# DL Lab: Colab challenge notebooks

Hands-on notebooks for the **Sequence Models & GANs** workshop. Open one in Google Colab, pick a dataset, fill in the `# TODO`s, train on a free GPU, and submit your result to DL Lab.

| Notebook | Open | Datasets you can pick |
|---|---|---|
| 📱 Read the vibe: RNN vs LSTM vs GRU | [Open in Colab](https://colab.research.google.com/github/Meet2147/dl-lab-notebooks/blob/main/notebooks/01_sequence_models.ipynb) | GoEmotions · Tweet → emoji · IMDB |
| 🗣️ Translate with attention | [Open in Colab](https://colab.research.google.com/github/Meet2147/dl-lab-notebooks/blob/main/notebooks/02_attention_translation.ipynb) | English → Hinglish · messy dates |
| 🎨 Make the machine draw | [Open in Colab](https://colab.research.google.com/github/Meet2147/dl-lab-notebooks/blob/main/notebooks/03_gans.ipynb) | Quick, Draw! · OpenMoji emoji · Fashion-MNIST · MNIST |

In Colab: **Runtime → Change runtime type → T4 GPU**, then paste the settings block from your DL Lab challenge page into the first cell.

Dataset credits: GoEmotions (Google, Apache-2.0), TweetEval (Cardiff NLP), IMDB (Stanford), English-to-Hinglish (findnitai, Apache-2.0), Quick, Draw! (Google, CC BY 4.0), OpenMoji (CC BY-SA 4.0), Fashion-MNIST (Zalando, MIT), MNIST.
